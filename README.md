# Grafana MCP

The official Grafana MCP server. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/@grafana/mcp-grafana

Installs from the Camillia hub as `grafana-mcp-cb1b24`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
